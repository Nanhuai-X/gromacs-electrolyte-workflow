# Third-party attribution

The package contains hand-authored workflow code and CP2K input skeletons.
The skeletons are intended to be checked against the official CP2K manuals
before use. Official documentation is not redistributed as a runtime cache.

Official sources referenced by the registry include:

- <https://manual.cp2k.org/cp2k-2024_1-branch/CP2K_INPUT.html>
- <https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT.html>

Optional integrations listed in `requirements-optional.txt` remain separate
third-party packages with their own licenses. Installing them is not required
for the standard-library orchestration scripts.
