# CP2K 2024.1 rules

## Manual gate

Use the exact branch recorded in `assets/template_registry.json`:

<https://manual.cp2k.org/cp2k-2024_1-branch/CP2K_INPUT.html>

Record the branch, retrieval time, content hash, consulted sections, and the
matching CP2K executable in `manual_manifest.yaml`.

## Version-specific checks

- Keep DOS and PDOS as the legacy sibling print sections. Do not copy the
  2026 nested `DOS/CURVE/PDOS` layout into a 2024.1 input.
- Verify the exact placement and meaning of virtual-state controls, including
  `ADDED_MOS`, against the manual before rendering a property input.
- If an OT recipe is used for geometry optimization, do not add an unnecessary
  explicit Gamma KPOINTS block without manual and executable evidence.
- Keep wavefunction restarts with the exact CP2K version/build that produced
  them; a 2026.2 restart is not automatically a 2024.1 restart.

The included templates are skeletons. Static lint only catches deterministic
mistakes; it cannot prove the exact 2024.1 binary accepts every property block.
The public registry therefore starts these capabilities as `NOT_VALIDATED`.
