# Multi-conformer RESP boundary

The Skill reserves a `MULTI_CONFORMER_RESP` profile, but it is
`NOT_YET_VALIDATED` until the installed Multiwfn version or an independently
validated implementation fits multiple conformers to one common charge set
with a shared atom map and documented weighting. Per-conformer RESP comparison
is allowed. Averaging independently fitted atom charges is not multi-conformer
RESP.
