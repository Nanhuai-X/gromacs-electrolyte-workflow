# Convergence gates

Thermodynamic convergence uses block means, standard deviations, drift or slope, and a representative final window. Structural convergence uses RDF/CN and contact or cluster trends with the same definitions across windows. No single final value proves a plateau. If the declared window is too short, return STATISTICALLY_UNRESOLVED.

NPT can be extended by the bounded default policy only when diagnostics require it. Never extend a run solely because a result is inconvenient.
